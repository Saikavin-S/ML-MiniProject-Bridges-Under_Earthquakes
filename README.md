## Problem Statement
 
Can we predict whether a bridge will be damaged in an earthquake based on:
- Bridge age (years)
- Earthquake magnitude (0-9 scale)
- Distance from epicenter (miles)
This is a **binary classification problem**: predict **Damaged (1)** or **Not Damaged (0)**.
